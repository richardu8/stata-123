# stata-123：单变量、双变量、多变量分析

依次做三步分析：单变量（描述统计）、双变量（各自变量分别与因变量的检验）、多变量（回归）。全部命令写进一个 do 文件，由 Stata 执行，结果从日志读回，写入用户指定的 Markdown 文件。

do 文件一律由 `assets/analysis-template.do` 生成，**只改文件头日期和参数区**。用哪种检验、哪种模型，由因变量类型、自变量类型与有无抽样设计事先决定，已写定在模板里，不因数据或结果而改动。同一类型内换模型（如 logit 换成修正泊松）只能由用户指定，不看显著性改换。

## 适用与不适用

- **适用**：横截面数据，包括带权数与复杂抽样设计的调查数据。因变量为二分类、连续、有序、无序多分类、计数或生存时间之一；自变量由用户分为连续、分类两类。
- **不适用**：面板固定效应与随机效应、多层模型、结构方程，以及工具变量、双重差分、断点回归、匹配等因果识别设计。遇到这些情况，停下说明本技能不适用；因果识别另用 stata-did、stata-iv、stata-rd、stata-matching 等技能。
- **只做三步**：用户没有要求的分析一律不做。可选模块（`references/optional-modules.md`）只在用户明确要求时做，包括：
  - 模型诊断
  - 平均边际效应
  - 导出 Word 表
  - 效应图
  - 稳健性检验
  - 分组描述图
  - 异质性分析
  - 多重插补
  - 生存曲线

## 一、确认参数

| `flag` | 分析样本标记变量名 | `analysis` | `analysis` |
| `savedata` | 1＝把标记变量存回数据文件 | 1 | 0 |

| 结果文件与标题 | 结果写入哪个 md、用什么标题 | `CLHLS2021-ADL失能影响因素分析.md`，“五、数据分析结果” | `results/analysis-results.md`，“数据分析结果” |

- **必填项缺失**：一次列出所缺各项再问，不猜。`xcont` 与 `xcat` 不能同时为空。
- **变量类型**：因变量类型与自变量类型都以用户的说法为准，不自行改划。用户没说明时，先只看不改地查看数据（`describe`、`tabulate`、`summarize`，或连接器的 `get_data_info`），按取值个数、是否有序、是否为计数、有无值标签提出建议，经用户确认后再运行。
- **抽样设计**：用户说明数据有权数或抽样设计（如 CHARLS、CFPS、CGSS 等调查的权数）时，向用户确认权数、PSU、分层变量名后填入。只有权数时只填 `wt`。用了抽样设计，`vce` 须留空。
- **修改数据文件**：用户明确说“可以修改数据库”或“可以修改数据文件”时，`savedata` 才设为 1；否则为 0，标记变量每次运行时重新生成。
- **参照组**：分类自变量默认以取值最小的类别为参照组；用户指定其他参照组时，在 `xcat` 里写 `ib#.变量名`，如 `ib2.a51`。
- **逐步加入变量**：用户说“分模型逐步加入”“模型 1 只放……”时，用 `blocks`。每个自变量恰好归入一组，组的顺序即加入顺序。

## 二、方法对照（事先定好，不随结果改动）

### 单变量

- **连续变量**：报告观测数、均值、标准差，包括连续自变量、连续或计数因变量与生存时间。
- **分类变量**：报告频数与百分比，包括分类自变量，以及二分类、有序、无序多分类因变量与失效指示变量。
- **抽样调查数据**：另报加权均值、加权标准差与加权百分比。

### 双变量：各自变量分别与因变量

一般数据：

| 因变量类型 | 连续自变量 | 分类自变量 |
| --- | --- | --- |
| 二分类 | 按因变量分两组的 t 检验 | 卡方检验；有单元格期望频数小于 5 时补报 Fisher 精确检验 |
| 连续 | Pearson 相关 | 两组用 t 检验，三组及以上用单因素方差分析 |
| 有序 | Spearman 等级相关 | 两组用 Wilcoxon 秩和检验，三组及以上用 Kruskal–Wallis 检验 |
| 无序多分类 | 自变量按因变量各类别分组的单因素方差分析 | 卡方检验；有单元格期望频数小于 5 时补报 Fisher 精确检验 |
| 计数（无暴露量） | Spearman 等级相关 | 两组用 Wilcoxon 秩和检验，三组及以上用 Kruskal–Wallis 检验 |
| 生存（cox、weibull） | 单变量生存回归，报告粗 HR | log-rank 检验 |

以下几种情况不分连续、分类自变量，每个自变量都单独进入同一类模型，报告粗效应：
- 有暴露量的计数因变量：报告粗 IRR，零膨胀模型改用对应的 poisson 或 nbreg；
- 竞争风险（crreg）：报告粗 SHR。

`unequal` 为 1 时，t 检验不假定两组方差相等，自由度用 Satterthwaite 近似。

抽样调查数据（检验按抽样设计计算，用 `subpop()` 限定分析样本）：

| 因变量类型 | 连续自变量 | 分类自变量 |
| --- | --- | --- |
| 二分类、无序多分类 | 自变量对因变量各类别回归的设计校正 F 检验 | Rao–Scott 校正的卡方检验（F 统计量） |
| 连续 | 单变量加权回归，另报加权相关系数 | 设计校正 F 检验 |
| 有序 | 单变量有序回归，报告粗效应 | Rao–Scott 校正的卡方检验 |
| 计数 | 单变量计数回归，报告粗 IRR | 单变量计数回归，报告粗 IRR |

### 多变量

| 因变量类型 | `model` | Stata 命令 | 报告的效应 |
| --- | --- | --- | --- |
| 二分类 | `logit`（缺省） | `logit …, or` | OR |
| 二分类 | `probit` | `probit` | 系数 |
| 二分类 | `lpm` | `regress …, vce(robust)` | 系数（概率差） |
| 二分类 | `mpoisson` | `poisson …, irr vce(robust)` | RR（横断面数据为患病率比） |
| 连续 | `ols`（缺省） | `regress` | 系数 |
| 连续 | `qreg` | `qreg …, quantile()` | 系数 |
| 连续 | `tobit` | `tobit …, ll() ul()` | 系数（潜变量） |
| 有序 | `ologit`（缺省） | `ologit …, or` | OR |
| 有序 | `oprobit` | `oprobit` | 系数 |
| 无序多分类 | `mlogit`（缺省） | `mlogit …, rrr baseoutcome()` | RRR |
| 计数 | `nbreg`（缺省） | `nbreg …, irr` | IRR |
| 计数 | `poisson` | `poisson …, irr` | IRR |
| 计数 | `zinb` | `zinb …, inflate() irr` | IRR；零膨胀方程为系数 |
| 计数 | `zip` | `zip …, inflate() irr` | IRR；零膨胀方程为系数 |
| 生存 | `cox`（缺省） | `stset`，再 `stcox` | HR |
| 生存 | `weibull` | `stset`，再 `streg …, distribution(weibull)` | HR |
| 生存 | `crreg` | `stset …, failure(y == 1)`，再 `stcrreg …, compete(y == 取值)` | SHR |

- **抽样设计**：各模型前加 `svy, subpop(analysis):`。`qreg` 与生存模型不支持，模板会提示。
- **逐步加入变量**：模型 1 只含第一组，此后逐组加入，最后一个为全模型；另报每组新增变量的联合检验。
- **联合检验**：三类及以上的分类自变量，在全模型中检验其各水平是否同时为 0。

### 计量要点

依据与文献见 `references/method-notes.md`。

- **标准误**：缺省为模型的常规标准误。样本有聚类结构（同一社区、学校、省份）时，用 `vce(cluster 聚类变量)`，聚类层级与抽样或处理分配的层级一致；聚类数很少时，聚类标准误本身也不可靠。`lpm` 的误差必然异方差，`mpoisson` 的泊松方差假定不适用于 0/1 因变量，二者都须用稳健标准误，模板自动加上。
- **抽样调查数据**：标准误由抽样设计决定。分析样本用 `subpop()` 而不用 `if` 限定，因为用 `if` 可能得到错误的标准误。模型整体检验为调整的 Wald 检验，F 的分母自由度为设计自由度减检验的项数再加 1。
- **OR 与 RR**：结局常见（发生率高于约 10%）时，OR 不再近似 RR，结局越常见偏离越大。需要报告“风险是几倍”时，由用户改用 `mpoisson`；不得把 OR 写成“风险是……倍”。
- **logit 系数的比较**：OR 也反映模型未纳入的异质性，在不同样本、不同组或自变量不同的模型之间直接比较须谨慎；对此方法学界有不同看法。写结果时不作这类比较，逐步加入变量前后 OR 的变化也不直接解读为中介或混杂的大小。
- **连续因变量**：`qreg` 估计条件分位数，适合偏态或关心分布不同位置的情形，不支持聚类标准误与抽样设计。`tobit` 用于在某一取值处删失的因变量，系数是对潜变量的效应。
- **有序模型**：ologit 假定各切点处自变量的效应相同（平行线假定），默认不检验，检验与替代模型见可选模块。
- **无序模型**：mlogit 不指定 `baseoutcome()` 时以频数最多的类别为基准，模板显式取 `base`（缺省为最小取值）；IIA 假定的常用检验表现不佳，不作为取舍模型的依据。
- **计数模型**：nbreg 在 alpha 为 0 时即为 poisson，输出自带 alpha=0 的似然比检验；零膨胀模型的 Vuong 检验，Stata 16 已提示不适合用于检验零膨胀，模板不做。
- **生存模型**：竞争事件会阻止关注的事件发生时（如死亡之于失能），用 `crreg`，报告子分布风险比 SHR，不写成风险比。
- **解释口径**：回归结果表示控制其他变量后的条件关联，不写成因果效应；伪 R² 不是 R²，不写“解释了百分之几的变异”。

## 三、检查环境

1. **执行方式**，按顺序选用：
   - **Stata 连接器（stata-mcp）**：用 `stata_do` 执行 do 文件，用 `read_log` 读日志。日志由连接器自动保存（通常在项目下的 `.statamcp/stata-mcp-log/`），所以 do 文件里不写 `log using`。项目路径须为全英文；路径含中文时，连接器回传结果会报编码错误，应提醒用户把项目复制到英文路径下再做。
   - **命令行批处理**：在项目根目录执行，日志生成在当前目录，与 do 文件同名（`analysis.log`）。
     - macOS：`/Applications/Stata/StataSE.app/Contents/MacOS/stata-se -b do do/analysis.do`。MP、BE 版把 `StataSE`、`stata-se` 换成相应名称；可用 `ls /Applications/Stata*/*.app/Contents/MacOS/` 查找。
     - Windows：`"C:\Program Files\Stata16\StataSE.exe" /e do do\analysis.do`，按实际的版本、安装位置与程序名改写（[GSW] B.5）。
     - Linux：`stata-se -b do do/analysis.do`，按安装位置补全路径（[GSU] B.3）。
   - **两者都没有**：只写 do 文件，请用户在 Stata 中运行，再把日志交回。不得编造或估计结果。
2. 三步分析只用 Stata 自带命令，不需要安装外部命令包。模板在 Stata 16 SE（macOS）上实测通过，其他版本与系统未测试。

## 四、生成 do 文件

1. 把 `assets/analysis-template.do` 复制到 do 文件位置。同名文件已存在时，先复制一份备份，文件名后加 `.bak`。
2. 只改两处：文件头的日期；参数区各参数。不用的参数留空，其余各段一字不改。
3. 参数行末的 `//` 注释前必须保留空格；值紧贴 `//` 时 Stata 会报语法错误 r(198)。`blocks` 中的 `|` 两侧可以有空格。
4. 改完核对：
   - 参数区的变量名与用户所给逐个一致；
   - `ytype` 与 `model` 相符，专用参数只填在对应的模型上；
   - `savedata` 与用户的授权一致。

模板各段依次为：（一）读入数据与检查；（二）单变量分析；（三）双变量分析；（四）多变量分析；（五）结果汇总。第（一）段的顺序为：
1. 检查参数与变量；
2. 列出各变量的缺失情况；
3. 生成标记变量；
4. 在分析样本内检查因变量与分类变量的编码；
5. 有抽样设计时，声明抽样设计。

生成标记变量的写法如下：

```stata
generate byte analysis = 1
markout analysis disabled age edu female urban a51   // 与 !missing(…) 等价
```

此后一般数据的每条分析命令都带 `if analysis == 1`，抽样调查数据的估计命令都用 `svy, subpop(analysis):`，任何观测都不删除。`time`、`exposure`、零膨胀方程的自变量、聚类变量与抽样设计变量也计入标记，保证各步样本一致。

## 五、运行与排错

1. 运行后先查错。**判断是否出错只看日志**：日志里出现 `r(数字);` 的行即为出错。命令行批处理即使出错，退出码也可能是 0。
2. 模板对常见问题给出中文提示：

| 日志中的错误 | 原因 | 处理 |
| --- | --- | --- |
| r(601) | 数据文件不存在 | 核对工作目录与 `data` 路径 |
| r(111) | 变量不存在 | 核对变量名（模板关闭了变量名缩写匹配，须写全） |
| r(7) | 有字符串变量 | 请用户先把该变量编码为数值 |
| r(198) | 参数有误，提示写明是哪一项：<br>- 类型或模型写错；<br>- 未列自变量，或同一变量列入两类，或因变量作自变量；<br>- 专用参数用错模型，或模型缺少必填的专用参数；<br>- `vce` 写法不对，或与抽样设计同时使用；<br>- `blocks` 分组不全或重复；<br>- `qreg`、生存模型与抽样设计同时使用 | 按提示改参数 |
| r(459) | 数据与类型不符，提示写明是哪一项：<br>- 因变量：二分类不是 0/1，有序或无序不足 3 个取值，计数含小数或负数，零膨胀模型没有 0 值，竞争风险的取值不对，有观测超出删失点；<br>- 其他变量：生存时间、暴露量、权数不大于 0，基准类别不存在，分类自变量含负数或小数 | 停下说明，请用户确认类型或处理数据 |

3. 不得为了跑通而改动模板的分析各段，不得删除观测、更换检验方法或模型。同一错误修改两次仍未解决，停下报告错误原文。
4. 写可选模块或帮用户整理变量时，对照 `references/stata-pitfalls.md`，避开缺失值、引号、权数、抽样设计与导出中的常见陷阱。

## 六、读结果

1. 写结果用的数字一律取自日志末尾“结果汇总”段的【……】行，并与前面各命令的完整输出对照。不估算、不手算、不凭记忆补数。
2. 写之前核对三项：
   - **样本量前后一致**：`【样本】`的分析样本、各分类变量频数之和、各检验的样本量、`【多变量-模型】`的 N（抽样调查数据为子总体观测数）。
   - **模型的提示**：须写进结果说明的情形如下。相关变量的效应不作解读，并提示用户考虑合并类别；不得自行合并。
     - 日志中有 `predicts success perfectly`、`predicts failure perfectly`、`omitted`、`not concave`、`convergence not achieved`；
     - 汇总段出现“注意：模型实际使用……”“模型未收敛”“无观测进入回归”“被略去”。
   - **卡方检验的“报告：”字段**：最小期望频数小于 5 的变量，报告 Fisher 精确检验的 p 值，并在表注中说明。
3. 效应名称以汇总行为准（OR、RR、IRR、RRR、HR、SHR 或系数），不得混用。mlogit 的每个效应都要写明是哪个结局相对基准类别；零膨胀模型的零膨胀方程另列，为系数。

## 七、写结果文件

1. 按 `references/report-template.md` 写：样本说明、单变量表、双变量表、多变量表、表注。
2. 结果文件已存在时，先备份，再把本节追加在文末，即用户所说的上一项任务结果之后。文件中已有同名标题时，替换该节内容，不重复追加。
3. 只写汇总统计量，不写任何个体记录。
4. 默认只给表格与表注。用户要求文字说明时，只复述表中数字，按效应名称措辞（如“发生比是……的 X 倍”“发生率是……的 X 倍”“风险比为 X”“子分布风险比为 X”“每增加一个单位，平均高出 X”），用“与……相关”，不写“导致”“影响了”这类因果判断。

## 八、交付前自检

- [ ] do 文件由模板生成，只改了日期与参数区；`ytype` 与 `model` 与用户所说一致。
- [ ] 一般数据的每条分析命令都带 `if analysis == 1`（或所设的标记名），抽样调查数据用 `subpop()`；没有删除观测的 `drop`、`keep`。
- [ ] 单变量：连续变量报告均值、标准差；分类变量报告频数、百分比；抽样调查数据注明加权。
- [ ] 双变量：检验方法与第二节对照表一致；期望频数小于 5 的改报 Fisher 精确检验。
- [ ] 多变量：效应名称、95% 置信区间、p 值、样本量与参照组都已写明；标准误类型与多分类变量的联合检验已在表注说明。
- [ ] 结果文件中的每个数字都能在日志里找到；样本量前后一致。
- [ ] 没有做用户未要求的分析；只在用户允许时修改了数据文件；改写已有文件前做了备份。
