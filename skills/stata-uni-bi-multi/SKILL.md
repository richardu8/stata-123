# Stata 单变量、双变量、多变量分析

依次做三步分析：单变量（描述统计）、双变量（各自变量分别与因变量的检验）、多变量（回归）。全部命令写进一个 do 文件，由 Stata 执行，结果从日志读回，写入用户指定的 Markdown 文件。

do 文件一律由 `assets/analysis-template.do` 生成，**只改文件头日期和参数区**。用哪种检验、哪种模型，由因变量类型与自变量类型事先决定，已写定在模板里，不因数据或结果而改动；同一类型内换模型（如 logit 换成修正泊松）只能由用户指定，不看显著性改换。

## 适用与不适用

- 适用：横截面数据，因变量为二分类、连续、有序、无序多分类、计数或生存时间之一；自变量由用户分为连续、分类两类。
- 不适用：抽样权数（svy）、面板与多层模型、工具变量、双重差分、断点回归、匹配等因果识别设计。遇到这些情况，停下说明本技能不适用；因果识别另用 stata-did、stata-iv、stata-rd、stata-matching 等技能。
- 用户没有要求的分析一律不做，包括边际效应、交互项、模型诊断、稳健性检验、导出 Word、作图。用户明确要求时，按 `references/optional-modules.md` 做。

## 一、确认参数

| 参数 | 含义 | 例 | 缺省 |
| --- | --- | --- | --- |
| `data` | 数据文件，相对项目根目录 | `inputs/clhls2021_analysis.dta` | 必填 |
| `ytype` | 因变量类型：`binary` `continuous` `ordinal` `nominal` `count` `survival` | `binary` | `binary` |
| `model` | 模型，见第二节多变量对照表 | `logit` | 该类型的缺省模型 |
| `y` | 因变量；`survival` 时为失效指示变量（0/1） | `disabled` | 必填 |
| `xcont` | 连续自变量 | `age edu` | 可空 |
| `xcat` | 分类自变量；改参照组写 `ib#.变量名` | `female urban a51` | 可空 |
| `time` | 生存时间变量，仅 `survival` 用 | `studytime` | `survival` 时必填 |
| `exposure` | 暴露量（如人年），仅 `count` 用 | `pyears` | 空 |
| `base` | 基准类别的取值，仅 `nominal` 用 | `1` | 最小取值 |
| `vce` | 标准误：空、`robust`，或 `cluster 聚类变量名` | `cluster prov` | 空，即模型的常规标准误 |
| `flag` | 分析样本标记变量名 | `analysis` | `analysis` |
| `savedata` | 1＝把标记变量存回数据文件 | 1 | 0 |
| do 文件位置 | 命令保存在哪里 | `do/analysis.do` | `do/analysis.do` |
| 结果文件与标题 | 结果写入哪个 md、用什么标题 | `CLHLS2021-ADL失能影响因素分析.md`，“五、数据分析结果” | `results/analysis-results.md`，“数据分析结果” |

- 必填项缺失时，一次列出所缺各项再问，不猜。`xcont` 与 `xcat` 不能同时为空。
- 因变量类型与自变量类型都以用户的说法为准，不自行改划。用户没说明时，先只看不改地查看数据（`describe`、`tabulate`、`summarize`，或连接器的 `get_data_info`），按取值个数、是否有序、是否为计数、有无值标签提出建议，经用户确认后再运行。
- 用户明确说“可以修改数据库”或“可以修改数据文件”时，`savedata` 才设为 1；否则为 0，标记变量每次运行时重新生成。
- 分类自变量默认以取值最小的类别为参照组；用户指定其他参照组时，在 `xcat` 里写 `ib#.变量名`，如 `ib2.a51`。

## 二、方法对照（事先定好，不随结果改动）

### 单变量

连续变量报告观测数、均值、标准差，包括连续自变量、连续或计数因变量与生存时间；分类变量报告频数与百分比，包括分类自变量以及二分类、有序、无序多分类因变量与失效指示变量。

### 双变量：各自变量分别与因变量

| 因变量类型 | 连续自变量 | 分类自变量 |
| --- | --- | --- |
| 二分类 | 按因变量分两组的 t 检验 | 卡方检验；有单元格期望频数小于 5 时补报 Fisher 精确检验 |
| 连续 | Pearson 相关 | 两组用 t 检验，三组及以上用单因素方差分析 |
| 有序 | Spearman 等级相关 | 两组用 Wilcoxon 秩和检验，三组及以上用 Kruskal–Wallis 检验 |
| 无序多分类 | 自变量按因变量各类别分组的单因素方差分析 | 卡方检验；有单元格期望频数小于 5 时补报 Fisher 精确检验 |
| 计数（无暴露量） | Spearman 等级相关 | 两组用 Wilcoxon 秩和检验，三组及以上用 Kruskal–Wallis 检验 |
| 生存 | 单变量 Cox 回归，报告粗 HR | log-rank 检验 |

有暴露量的计数因变量比较的是发生率：每个自变量，不论连续还是分类，都单独进入同一计数模型（含暴露量），报告粗 IRR。t 检验均为两组方差相等的 Student t 检验。

### 多变量

| 因变量类型 | `model` | Stata 命令 | 报告的效应 |
| --- | --- | --- | --- |
| 二分类 | `logit`（缺省） | `logit …, or` | OR |
| 二分类 | `probit` | `probit` | 系数 |
| 二分类 | `lpm` | `regress …, vce(robust)` | 系数（概率差） |
| 二分类 | `mpoisson` | `poisson …, irr vce(robust)` | RR（横断面数据为患病率比） |
| 连续 | `ols`（缺省） | `regress` | 系数 |
| 有序 | `ologit`（缺省） | `ologit …, or` | OR |
| 有序 | `oprobit` | `oprobit` | 系数 |
| 无序多分类 | `mlogit`（缺省） | `mlogit …, rrr baseoutcome()` | RRR |
| 计数 | `nbreg`（缺省） | `nbreg …, irr` | IRR |
| 计数 | `poisson` | `poisson …, irr` | IRR |
| 生存 | `cox`（缺省） | `stset`，再 `stcox` | HR |

### 计量要点

依据与文献见 `references/method-notes.md`。

- **标准误**：缺省为模型的常规标准误。样本有聚类结构（同一社区、学校、省份）时，用 `vce(cluster 聚类变量)`，聚类层级与抽样或处理分配的层级一致；聚类数很少时，聚类标准误本身也不可靠。`lpm` 的误差必然异方差，`mpoisson` 的泊松方差假定不适用于 0/1 因变量，二者都须用稳健标准误，模板自动加上。
- **OR 与 RR**：结局常见（发生率高于约 10%）时，OR 不再近似 RR，结局越常见偏离越大。需要报告“风险是几倍”时，由用户改用 `mpoisson`；不得把 OR 写成“风险是……倍”。
- **logit 系数的比较**：OR 也反映模型未纳入的异质性，在不同样本、不同组或自变量不同的模型之间直接比较须谨慎；对此方法学界有不同看法，写结果时不作这类比较。
- **有序模型**：ologit 假定各切点处自变量的效应相同（平行线假定），默认不检验，检验与替代模型见可选模块。
- **无序模型**：mlogit 不指定 `baseoutcome()` 时以频数最多的类别为基准，模板显式取 `base`（缺省为最小取值）；IIA 假定的常用检验表现不佳，不作为取舍模型的依据。
- **计数模型**：nbreg 在 alpha 为 0 时即为 poisson，输出自带 alpha=0 的似然比检验；选 poisson 时，离散程度的检验见可选模块。
- **解释口径**：回归结果表示控制其他变量后的条件关联，不写成因果效应；伪 R² 不是 R²，不写“解释了百分之几的变异”。

## 三、检查环境

1. **执行方式**，按顺序选用：
   - **Stata 连接器（stata-mcp）**：用 `stata_do` 执行 do 文件，用 `read_log` 读日志。日志由连接器自动保存（通常在项目下的 `.statamcp/stata-mcp-log/`），所以 do 文件里不写 `log using`。项目路径须为全英文；路径含中文时，连接器回传结果会报编码错误，应提醒用户把项目复制到英文路径下再做。
   - **命令行批处理**：在项目根目录执行，日志生成在当前目录，与 do 文件同名（`analysis.log`）。
     - macOS：`/Applications/Stata/StataSE.app/Contents/MacOS/stata-se -b do do/analysis.do`。MP、BE 版把 `StataSE`、`stata-se` 换成相应名称；可用 `ls /Applications/Stata*/*.app/Contents/MacOS/` 查找。
     - Windows：`"C:\Program Files\Stata18\StataSE-64.exe" /e do do\analysis.do`，按实际版本与安装位置改写。
     - Linux：`/usr/local/stata18/stata-se -b do do/analysis.do`。
   - **两者都没有**：只写 do 文件，请用户在 Stata 中运行，再把日志交回。不得编造或估计结果。
2. 三步分析只用 Stata 自带命令，不需要安装外部命令包。模板在 Stata 16 上实测通过，更早的版本未测试。

## 四、生成 do 文件

1. 把 `assets/analysis-template.do` 复制到 do 文件位置。同名文件已存在时，先复制一份备份，文件名后加 `.bak`。
2. 只改两处：文件头的日期；参数区的 `data`、`ytype`、`model`、`y`、`xcont`、`xcat`、`time`、`exposure`、`base`、`vce`、`flag`、`savedata`。不用的参数留空，其余各段一字不改。
3. 参数行末的 `//` 注释前必须保留空格；值紧贴 `//` 时 Stata 会报语法错误 r(198)。
4. 改完核对：参数区的变量名与用户所给逐个一致；`ytype` 与 `model` 相符；`savedata` 与用户的授权一致。

模板各段依次为：（一）读入数据与检查；（二）单变量分析；（三）双变量分析；（四）多变量分析；（五）结果汇总。第（一）段先检查参数与变量，再生成标记变量，然后在分析样本内检查因变量与分类变量的编码：

```stata
generate byte analysis = 1
markout analysis disabled age edu female urban a51   // 与 !missing(…) 等价
```

此后每条分析命令都带 `if analysis == 1`，任何观测都不删除。`time`、`exposure` 与聚类变量也计入标记，保证各步样本一致。

## 五、运行与排错

1. 运行后先查错。**判断是否出错只看日志**：日志里出现 `r(数字);` 的行即为出错。命令行批处理即使出错，退出码也可能是 0。
2. 模板对常见问题给出中文提示：

| 日志中的错误 | 原因 | 处理 |
| --- | --- | --- |
| r(601) | 数据文件不存在 | 核对工作目录与 `data` 路径 |
| r(111) | 变量不存在 | 核对变量名（模板关闭了变量名缩写匹配，须写全） |
| r(7) | 有字符串变量 | 请用户先把该变量编码为数值 |
| r(198) | 参数有误：类型或模型写错、未列自变量、同一变量列入两类、因变量作自变量、专用参数用错类型、`vce` 写法不对 | 按提示改参数 |
| r(459) | 数据与类型不符：二分类不是 0/1、有序或无序不足 3 个取值、计数含小数或负数、生存时间不大于 0、暴露量不大于 0、基准类别不存在、分类自变量含负数或小数 | 停下说明，请用户确认类型或处理数据 |

3. 不得为了跑通而改动模板的分析各段，不得删除观测、更换检验方法或模型。同一错误修改两次仍未解决，停下报告错误原文。

## 六、读结果

1. 写结果用的数字一律取自日志末尾“结果汇总”段的【……】行，并与前面各命令的完整输出对照。不估算、不手算、不凭记忆补数。
2. 写之前核对三项：
   - **样本量前后一致**：`【样本】`的分析样本、各分类变量频数之和、各检验的样本量、`【多变量-模型】`的 N。
   - **模型的提示**：日志中有 `predicts success perfectly`、`predicts failure perfectly`、`omitted`、`not concave`、`convergence not achieved`，或汇总段出现“注意：模型实际使用……”“模型未收敛”“无观测进入回归”“被略去”时，必须写进结果说明，相关变量的效应不作解读，并提示用户考虑合并类别；不得自行合并。
   - **卡方检验的“报告：”字段**：最小期望频数小于 5 的变量，报告 Fisher 精确检验的 p 值，并在表注中说明。
3. 效应名称以汇总行为准（OR、RR、IRR、RRR、HR 或系数），不得混用；mlogit 的每个效应都要写明是哪个结局相对基准类别。

## 七、写结果文件

1. 按 `references/report-template.md` 写：样本说明、单变量表、双变量表、多变量表、表注。
2. 结果文件已存在时，先备份，再把本节追加在文末，即用户所说的上一项任务结果之后。文件中已有同名标题时，替换该节内容，不重复追加。
3. 只写汇总统计量，不写任何个体记录。
4. 默认只给表格与表注。用户要求文字说明时，只复述表中数字，按效应名称措辞（如“发生比是……的 X 倍”“发生率是……的 X 倍”“风险比为 X”“每增加一个单位，平均高出 X”），用“与……相关”，不写“导致”“影响了”这类因果判断。

## 八、交付前自检

- [ ] do 文件由模板生成，只改了日期与参数区；`ytype` 与 `model` 与用户所说一致。
- [ ] 每条分析命令都带 `if analysis == 1`（或所设的标记名），没有删除观测的 `drop`、`keep`。
- [ ] 单变量：连续变量报告均值、标准差；分类变量报告频数、百分比。
- [ ] 双变量：检验方法与第二节对照表一致；期望频数小于 5 的改报 Fisher 精确检验。
- [ ] 多变量：效应名称、95% 置信区间、p 值、样本量与参照组都已写明；用了稳健或聚类标准误的已在表注说明。
- [ ] 结果文件中的每个数字都能在日志里找到；样本量前后一致。
- [ ] 没有做用户未要求的分析；只在用户允许时修改了数据文件；改写已有文件前做了备份。

## 文件

- `assets/analysis-template.do`：do 文件模板。
- `references/report-template.md`：结果文件的写法与各类型的表格样式。
- `references/method-notes.md`：方法依据，即各模型的假定、标准误、诊断与解释要点及文献。
- `references/optional-modules.md`：可选模块，包括模型诊断、平均边际效应、结果导出、作图、稳健性检验，只在用户明确要求时使用。
